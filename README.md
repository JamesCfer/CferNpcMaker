# CferNpcMaker

Four sibling Foundry VTT modules for AI-assisted NPC and item generation:

| Module            | System  | Generates                              | Output lands in |
| ----------------- | ------- | -------------------------------------- | --------------- |
| `Pf2eNpcMaker`    | `pf2e`  | NPC actors (with level-up + image)     | `game.actors`   |
| `DnD5eNpcMaker`   | `dnd5e` | Creature actors (with CR + spells)     | `game.actors`   |
| `Hero6eNpcMaker`  | `hero6e`| Characters (via HDC import)            | `game.actors`   |
| `Pf2eItemMaker`   | `pf2e`  | Items (weapons, armor, consumables…)   | `game.items`    |

## Repository layout

Each release ships only the code it needs. The home tab inside the builder
links to the other three modules so users can install them too.

```
/shared/                          source of truth (not shipped directly)
  scripts/core/                   app, auth, history, feedback, image,
                                  update-check, sidebar, storage, n8n,
                                  home-data, utils, adapter base class
  styles/core.css
  templates/shell.html
  templates/home.html

/modules/<Name>/                  per-module overlay (also not shipped directly)
  module.json
  scripts/
    entry.js                      registers hooks, opens the builder
    adapter.js                    SystemAdapter subclass for this module
    sanitizer.js                  system-specific data cleanup
  styles/accents.css
  templates/form.html

<Name>/                           build output — the shipped Foundry module
                                  (generated by build.sh; git-ignored)
```

## Building

To produce a shipped module locally (e.g. to symlink into Foundry's
`Data/modules/`):

```sh
./build.sh Pf2eNpcMaker                 # one module
./build.sh Pf2eNpcMaker DnD5eNpcMaker   # several
./build.sh Pf2eNpcMaker DnD5eNpcMaker Hero6eNpcMaker Pf2eItemMaker   # all
```

The script copies `shared/scripts/core/` into each output's `scripts/core/`,
concatenates `shared/styles/core.css` with `modules/<Name>/styles/accents.css`,
and splices `shared/templates/home.html` + `modules/<Name>/templates/form.html`
into `shared/templates/shell.html`.

## Releasing

Bumping `version.json` on `main` triggers
`.github/workflows/release.yml`, which runs `build.sh` for all four modules,
pushes each output to its own GitHub repo
(`JamesCfer/<Name>`), and uploads a versioned + floating-`latest` release.
